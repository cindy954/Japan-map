# 🇯🇵 일본 맛집 캡쳐 → 구글맵 + 타베로그 변환기

인스타 릴스·네이버 블로그 캡쳐(여러 장)나 복사해 둔 리스트에서 **일본어 가게명만** 뽑아
**구글맵 / 타베로그 / 이름 복사** 버튼을 한 번에 만들어 주는 모바일 웹툴입니다.

- 만든 사람: 신디 `@cindy_travelus`
- 설치 없음, API 키 없음 — **정적 파일** + 사진 인식용 AI 비전 서버(Cloudflare Worker) 한 개.
- 사진은 가게명 인식에만 쓰고 저장하지 않아요. AI가 안 되면 브라우저 OCR로 자동 전환돼요.

## 파일 구성

```
index.html    화면 (모바일 우선, 라이트 톤 카드 UI)
styles.css    스타일
parser.js     일본어 가게명 추출 · AI 결과 정리 · 링크 생성 (DOM 없이 동작, node로 테스트 가능)
app.js        화면 조작 · AI 비전 호출 · Tesseract.js OCR 폴백 · 결과 카드
```

모든 경로는 상대 경로라서 GitHub Pages 서브 폴더(`/Japan-map/` 같은)에서도 그대로 동작합니다.

## 기능

1. **입력 두 가지**
   - 사진 업로드: `<input type="file" accept="image/*" multiple>` — 여러 장 동시 선택, 썸네일, 장당 진행률 + 전체 진행률
   - 텍스트 붙여넣기: 캡션·리스트를 그대로 붙여넣고 변환
2. **AI 비전 인식(기본 엔진)** — 사진을 긴 변 1400px · JPEG 품질 0.85로 가볍게 줄여 `POST https://polished-shape-141d.rlatlsel12.workers.dev` (`{ imageBase64, mimeType }`)로 보내고 `{ places: ["가게명", …] }`를 받습니다. 한 장에 보통 1~2초, 여러 장은 순서대로 처리하면서 장당 진행 상태(썸네일 `AI` → `AI 완료`)와 전체 진행률을 보여 줍니다.
   - 이름 끝에 붙은 말줄임표(`...`, `…`)는 검색 정확도를 위해 자동으로 떼어 냅니다(구글맵·타베로그 쿼리에서도 제거).
3. **안전 폴백** — AI 요청이 네트워크 오류·429(무료 한도 초과)·5xx·시간 초과로 실패하면 결과를 포기하지 않고 `Tesseract.js 5`(`jpn+eng+kor`) 브라우저 OCR로 자동 전환합니다. 화면에는 "AI 한도 초과/연결 지연으로 기본 OCR 모드로 전환했어요" 배지와 사유가 뜨고, [AI로 다시 시도] 버튼으로 다시 AI 경로를 쓸 수 있어요.
   - 429는 새로고침 전까지 OCR로 계속 가고, 네트워크·5xx는 그 묶음만 OCR로 마무리한 뒤 다음 실행에서 AI를 다시 시도합니다.
4. **자동 분류** — 일본어(한자/가타카나/히라가나) 줄은 자동 체크, 아래는 "후보에서 뺀 줄"로 접힘. 체크 토글로 언제든 되돌릴 수 있고, 이름은 인라인 수정 가능.
   - 한국어 설명·시간·가격·URL·해시태그·전화번호
   - 구글맵 UI 문구(메뉴·리뷰·사진·경로·저장·영업 중 / メニュー·口コミ·写真·経路·保存·営業中 …)
   - 한두 글자만 튀어나온 잡음(지도·간판 글씨), 주소 줄(大阪市中央区1-2-3), OCR이 잘못 읽어 생긴 기호 덩어리
   - 단, `本店`·`支店`·`2号店`처럼 이름이 쪼개져 생긴 꼬리 조각은 후보로 남겨서 합치기에 쓸 수 있게 함
5. **지역 칩** — 일본 전체 / 오사카 / 도쿄 / 나고야 / 후쿠오카 / 교토 / 삿포로
   - 구글맵 검색어에 지역명(大阪·東京·名古屋·福岡·京都·札幌)이 붙음
   - 타베로그는 지역 경로(`/osaka/`, `/aichi/` …)로 좁혀서 검색
6. **가게별 버튼** — 📍 구글맵 / 🍽️ 타베로그 / 📋 이름 복사 (클립보드 실패 시 execCommand 폴백)
7. **일괄 복사** — 이름만 / 구글맵 링크까지
8. **선택한 줄 합치기** — 이름이 여러 줄로 쪼개졌을 때(간판·지도 글씨가 섞여서) 결과 카드에서 원하는 줄을 체크하고 [합치기]를 누르면 한 줄로 붙여 줍니다. 일본어는 띄어쓰기 없이, 영문·숫자 사이만 띄워서 합칩니다.
9. **예시 버튼** — 처음 방문자용 샘플 리스트(오사카·나고야 유명 맛집 4곳)

## 링크 규칙

- 구글맵: `https://www.google.com/maps/search/?api=1&query=<가게명 + 지역명>`
- 타베로그: `https://tabelog.com/<지역>/rstLst/?sw=<일본어 가게명>` (지역 미선택 시 `https://tabelog.com/rstLst/?sw=…`)

가게명에 한국어가 섞여 있으면 타베로그 검색어로는 일본어 부분만 씁니다.

## AI 비전 서버

- 엔드포인트: `https://polished-shape-141d.rlatlsel12.workers.dev` (Cloudflare Worker → Workers AI 비전 모델)
- 요청: `POST` `application/json` — `{ "imageBase64": "…", "mimeType": "image/jpeg" }`
- 응답: `{ "places": ["だるま 新世界総本店", "自由軒 難波本店", …] }`
- CORS 허용 오리진이 `https://cindy954.github.io` 하나로 고정돼 있어요. 로컬(`file://`, `localhost`)에서 열면 브라우저가 요청을 막기 때문에 자동으로 OCR 폴백으로 동작합니다. AI 경로를 로컬에서 보고 싶으면 Worker의 `Access-Control-Allow-Origin`에 그 오리진을 추가해야 해요.
- 엔드포인트를 바꿀 때는 `app.js` 맨 위 `VISION_ENDPOINT` 한 곳만 고치면 됩니다.

## 알려진 한계

- AI 비전은 Cloudflare Workers AI 무료 한도를 씁니다. 한도를 넘으면 자동으로 브라우저 OCR로 전환돼요(이때 첫 실행에 일본어·영어·한국어 인식 데이터 약 35MB를 한 번 내려받습니다).
- 사진은 인식을 위해 Cloudflare Worker로 전송되며, 서비스 쪽에서 저장하지 않습니다. 민감한 화면(개인정보·결제정보)은 올리지 마세요.
- 세로쓰기 일본어 메뉴판(`jpn_vert`)은 지원하지 않습니다. 가로쓰기 캡쳐/리스트에 최적화.
- 인식 특성상 오인식이 있을 수 있어, 결과는 항상 화면에서 확인·수정하는 걸 전제로 만들었습니다.
- 타베로그는 봇 차단이 있어 프로그램으로 결과를 긁어오지 않습니다. 링크만 열어 줍니다.
