# 🇯🇵 일본 맛집 캡쳐 → 구글맵 + 타베로그 변환기

인스타 릴스·네이버 블로그 캡쳐(여러 장)나 복사해 둔 리스트에서 **일본어 가게명만** 뽑아
**구글맵 / 타베로그 / 이름 복사** 버튼을 한 번에 만들어 주는 모바일 웹툴입니다.

- 만든 사람: 신디 `@cindy_travelus`
- 설치 없음, 서버 없음, API 키 없음 — **정적 파일만** 있으면 동작합니다.
- 사진은 업로드되지 않고 브라우저 안에서만 OCR 됩니다.

## 파일 구성

```
index.html    화면 (모바일 우선, 라이트 톤 카드 UI)
styles.css    스타일
parser.js     일본어 가게명 추출 · 링크 생성 (DOM 없이 동작, node로 테스트 가능)
app.js        화면 조작 · Tesseract.js OCR · 결과 카드
```

모든 경로는 상대 경로라서 GitHub Pages 서브 폴더(`/Japan-map/` 같은)에서도 그대로 동작합니다.

## 기능

1. **입력 두 가지**
   - 사진 업로드: `<input type="file" accept="image/*" multiple>` — 여러 장 동시 선택, 썸네일, 장당 진행률 + 전체 진행률
   - 텍스트 붙여넣기: 캡션·리스트를 그대로 붙여넣고 변환
2. **무료 브라우저 OCR** — Tesseract.js 5 (`jpn+eng+kor`) CDN 로드. 한국어 캡션은 한국어로 읽어 노이즈로 보내고, 일본어 가게명만 후보로 남깁니다. 아주 큰 사진만 2400px로 줄이고 나머지는 원본 그대로 인식(전처리하면 오히려 한자 정확도가 떨어져서요).
3. **자동 분류** — 일본어(한자/가타카나/히라가나)가 2자 이상인 줄은 자동 체크, 한국어 설명·시간·가격·URL·해시태그·전화번호는 "후보에서 뺀 줄"로 접힘. 체크 토글로 언제든 되돌릴 수 있고, 이름은 인라인 수정 가능.
4. **지역 칩** — 일본 전체 / 오사카 / 도쿄 / 나고야 / 후쿠오카 / 교토 / 삿포로
   - 구글맵 검색어에 지역명(大阪·東京·名古屋·福岡·京都·札幌)이 붙음
   - 타베로그는 지역 경로(`/osaka/`, `/aichi/` …)로 좁혀서 검색
5. **가게별 버튼** — 📍 구글맵 / 🍽️ 타베로그 / 📋 이름 복사 (클립보드 실패 시 execCommand 폴백)
6. **일괄 복사** — 이름만 / 구글맵 링크까지
7. **예시 버튼** — 처음 방문자용 샘플 리스트(오사카·나고야 유명 맛집 4곳)

## 링크 규칙

- 구글맵: `https://www.google.com/maps/search/?api=1&query=<가게명 + 지역명>`
- 타베로그: `https://tabelog.com/<지역>/rstLst/?sw=<일본어 가게명>` (지역 미선택 시 `https://tabelog.com/rstLst/?sw=…`)

가게명에 한국어가 섞여 있으면 타베로그 검색어로는 일본어 부분만 씁니다.

## 배포 (GitHub Pages)

1. 이 폴더의 파일 4개를 저장소 루트(또는 하위 폴더)에 올리기
2. Settings → Pages → Source: `Deploy from a branch` → Branch `main`, 폴더 `/ (root)`
3. `https://<아이디>.github.io/<저장소>/` 로 접속

## 알려진 한계

- 첫 OCR 실행 때 일본어·영어·한국어 인식 데이터(약 35MB)를 한 번 내려받습니다. 이후엔 브라우저 캐시를 씁니다.
- 세로쓰기 일본어 메뉴판(`jpn_vert`)은 지원하지 않습니다. 가로쓰기 캡쳐/리스트에 최적화.
- OCR 특성상 오인식이 있을 수 있어, 결과는 항상 화면에서 확인·수정하는 걸 전제로 만들었습니다.
- 타베로그는 봇 차단이 있어 프로그램으로 결과를 긁어오지 않습니다. 링크만 열어 줍니다.
